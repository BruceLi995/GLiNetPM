Brume 4/Pro产品规划

Brume 系列自初代（2019 VPN 盒子）到 Brume 3（2026 高性能 VPN 安全网关）始终以「OpenWrt 开放性 + 无 Wi-Fi 纯网关 + 高性价比」从底部渗透。Brume 4 / Pro 的代际跃迁核心，是把 Brume 3 缺失的安全底座（IDS/IPS + VLAN + 可视化防火墙 + 日志审计）补齐，同时守住已验证的「易用 + VPN + 低功耗」护城河，从纯 VPN 网关升级为安全网关 / 安全中枢。

定位护城河与最大风险

机型必须守住的护城河最大风险
Brume 4VPN 混淆 + Tailscale 原生 + 超低功耗(<5W) + 开箱易用（Brume 3 已验证、竞品难抄）为堆参数牺牲易用性；性能不足
Brume Pro同上 + 全开放 Suricata + 核心安全零订阅安全深度不足却收费；缺可视化防火墙与审计留痕；成本过高

不可妥协的产品红线：核心安全零订阅 + 开箱即用的可视化防火墙与审计（Firewalla 已验证、Brume Pro 必须正面超越的标杆）。

用户反馈三源（Reddit r/GlInet、GL 官方论坛、电商官网/Amazon）的跨源强共识显示：最主流场景是「家庭 VPN 服务端 + 旅行路由作客户端」，第二主流是「旁路由/Drop-in + AdGuard/VPN」；真实但偏技术客群的需求是「纯有线网关 + 端口数 + 网络分段」。这些场景同时覆盖了 Brume 4 与 Brume Pro 的适用面。

Brume 4 目标用户

  • 无 IT 的小微企业 / 分支 / 咖啡馆 / 诊所 / 小工作室：需要开箱安全网关心智，不愿养专业网管。
  • 技术 DIY 但嫌 RouterOS 门槛高的用户：想要企业级安全（VLAN/IPS）却不愿学命令行。
  • 家庭进阶用户：想要网络分段、IoT/Guest 隔离、家长控制的可视化配置。
  • 出差 / 跨境办公人群：VPN 强项（WireGuard 1100+Mbps + 混淆 + Tailscale 原生）延续 Brume 3 优势。

Brume Pro 目标用户

  • 重视安全的高阶家庭 / SOHO：Firewalla 用户的最佳平替（约半价、零订阅）。
  • 多分支小企业 / 连锁门店：需要多站点 SD-WAN、审计中心与合规导出。
  • MSP / 企业 IT：多租户批量运维、主动健康告警、合规留痕。
  • 智能家庭 / 多设备 IoT 用户：需要设备级流量洞察与 AI 行为分析。

Brume 4核心卖点

  • 开箱即用的安全底座：IDS/IPS + 原生 VLAN + 可视化 Zone/应用级防火墙 + 日志审计，无需订阅。
  • 比 Fusion 更安全、比 hEX 更易用：无 IT 小微企业 $179 级安全基础设施。
  • VPN 强项延续：WireGuard 1100+Mbps + 混淆 + Tailscale/ZeroTier 原生，跨境/远程接入无忧。
  • 超低功耗 <5W、静音、弱电箱神器：7×24 部署无负担。
  • 免 license GoodCloud 云管理 + App/Web 双管理，多站点轻量运维。
  • 支持多种部署模式，适应各种网络部署需求。
  • 高性价比：价格亲民，补齐全竞品安全门槛却不抬高拥有成本。

Brume Pro 核心卖点

  • Firewalla 一半价格、零订阅的企业级安全中枢：正面取代其范式。
  • 全开放 Suricata 10000+ 规则 + Zone 防火墙 + 防火墙/IDS 统一策略编排。
  • 设备级 AI 行为分析 + 流量洞察，新设备自动隔离、一键 Lockdown。
  • 审计中心：日志留存 + 报表 + 合规导出；多站点 SD-WAN + MSP 多租户。
  • ZTNA 零信任 + Docker + 可选 NVMe 本地存储（审计/缓存/轻量 NVR/轻量NAS 潜力）。
  • 安全仪表盘，全网安全态势统一可视化。
  • 同样守住 VPN/低功耗/易用护城河，安全深度对标 $629 竞品却仅其半价。

共同卖点（三代传承的护城河）

  • OpenWrt 开放性 + 无 Wi-Fi 纯网关形态 + 高性价比：从初代到 Pro 一以贯之。
  • 核心安全零订阅（产品红线）：对抗一切付费签名 / license 云范式的根本差异点。
  • 开箱易用 + 可视化：把企业级安全做成消费级体验，是竞争中最稀缺的组合。
